## Integration (13/15 wired)

The seam, candidate chains, wire names, `MPV_KIT_VIDEO_API`, hwdec defaults per backend, DRM render-node plumbing, events, dispose order, fault test, forced-backend matrix, the macOS route and the LGPL/ANGLE gates are all wired (integration checker report, static trace at 6407ea0).

Broken: the consumer path through the pinned bundle.
- **INT-1** — `bundleTag = 'v0.1.0-dev.3'` (2026-10-16) predates the Windows D3D11 build (73ce42a, patch 0010). Verified: `git merge-base --is-ancestor 73ce42a v0.1.0-dev.3` is false.
- **INT-2** — the same tag predates the Linux GL build (5c2b060). Verified the same way.

Both fall through gracefully (Vulkan first, then software), so a consumer with working Vulkan sees no change. The new backends only help once a new bundle is released and pinned.
