运行条件（Phase 7/12/14 的教训）：桌面解锁、示例窗口全程可见不被遮挡、没有其他占用 GPU 的程序、宿主盘可用空间不少于 5.5 GB；固定 SDK `/d/flutter/bin/flutter`（3.47.8）；Git Bash 下 PATH 条目用 POSIX 形式。
