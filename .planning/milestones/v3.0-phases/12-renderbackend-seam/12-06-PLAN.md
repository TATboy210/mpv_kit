<objective>
把原生 reason 改成 ADR 0004 定稿的语法（RBE-07 原生侧），在代码搬迁之前完成，使之后的搬迁只需保持字符串逐字不变。这是一次刻意的、非搬迁的行为变更，单独提交；golden_sw 中 reason 行在同一提交里更新——这是本阶段唯一允许修改 sw.txt reason 行的提交。

当前字符串（video_renderer.cc:47-62、:119-129）与新语法的差别：成功但有失败候选时 `; gpu-next unavailable: …` 缺 api 前缀；全部失败时是 `software (mpv_render_context_create: gpu-next unavailable: E1, gpu unavailable: E2)`；显式 software 是 `software (software rendering requested)`；Linux 插件另外在末尾拼 `: <gl_reason>`（mpv_kit_video_plugin.cc:349-351）。

Purpose: 后续阶段的 CI 矩阵（Phase 17 VER-02）与 macOS 的 `via MoltenVK`（Phase 13）都按 reason 前缀断言实际后端；语法若在搬迁之后才改，搬迁期间的「reason 不变」就无从比较。
Output: 新语法的 reason 组装与清洗、Linux interopReason、golden 更新。
</objective>
