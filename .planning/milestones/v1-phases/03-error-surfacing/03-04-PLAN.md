<objective>
Make the two remaining silent error sites observable without breaking anything: option names mpv does not know (typos, newer-mpv options, reduced builds) and libmpv library resolution fall-throughs.

Purpose: `Mpv.create` swallows every `optionNotFound` (mpv.dart:63,76) — the same swallow that legitimately tolerates newer-mpv options also hides typos for all `Player` defaults (player.dart:88-106). `MpvLibrary.open` (library.dart:49-70) silently falls through from a failed `MPV_KIT_LIBMPV_PATH` to the platform default — the Phase 1 closeout documented a real incident where tests measured the wrong DLL. Both need recording/exposure (OBS-04), while create must keep not throwing.

Output: additive diagnostic statics + developer.log on `MpvLibrary`, an ignored-options seam on `Mpv`, a tolerant shader-cache-dir setup, and tests.
</objective>
