<objective>
Route property-observation and event-parse failures to `Player.errors`, keep the native event drain alive under any single-event failure, and rebaseline the post-dispose semantics of `errorString`/`eventName` (IN-02).

Purpose: `Player._bind` (player.dart:711) subscribes with no `onError`, so an `observe_property` registration failure delivered via `controller.addError` (mpv.dart:481-484) becomes an uncaught async error that never reaches `Player.errors`; a throwing state parser (player.dart:711) and an `UnsupportedError` from `readNode` (node.dart:47 via events.dart:71-78) propagate through the `sync: true` observer controllers into `_onWakeup`'s drain loop (mpv.dart:636-642), aborting delivery of every later queued event.

Output: guarded `_dispatch`, error-aware `_bind`, drained-safe completions, and the IN-02 rebaseline.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| native event thread -> Dart drain | Event payloads are untrusted shapes; one bad event must not kill the pump |
| generated parsers -> state values | Parsers assume documented node shapes; real mpv can violate them |
| abandoned futures -> zone | Replies completed after their listener is gone become unhandled errors |
