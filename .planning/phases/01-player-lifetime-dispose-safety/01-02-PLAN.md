<objective>
Guarantee that no public `Mpv` method can enter native code after `dispose()`.

Purpose: `Mpv` keeps a raw `mpv_handle*` in a `final` field. After `mpv_terminate_destroy`, any public method still reaches libmpv and produces a process-level use-after-free instead of a Dart exception. Adding one guard at every public entry point converts that crash into a predictable `StateError`, and a test-only counter proves the native boundary was never crossed.

Output: guarded `mpv.dart`; an API-table regression test in `mpv_test.dart` that proves both the exception and the absence of native entries.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| application code -> `Mpv` | Any late timer, widget callback, or plugin event can call the wrapper after teardown |
| `Mpv` -> libmpv FFI | The raw `mpv_handle*` is invalid once `mpv_terminate_destroy` returns |
| pre-created stream -> `onListen` | A stream can be subscribed after the owning handle is gone |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-06 | Tampering | `observeProperty` late listen | high | mitigate | `onListen` checks `_disposed` and delivers `StateError` without calling `bindings.observeProperty`. |
