<objective>
Make `Player.dispose()` exception-safe and make every state/event stream close deterministically.

Purpose: The two confirmed lifetime defects — `position`/`decodeWarning` controllers missing from `_states`, and a dispose chain that aborts on the first throwing hook — are the root cause of leaked native cores and listeners that never receive `done`. This plan establishes the end-to-end teardown path the rest of the phase builds on.

Output: `player.dart` and `mpv.dart` with ordered, exception-isolated teardown; regression tests in `player_test.dart` and `mpv_test.dart`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Dart isolate -> libmpv FFI | Every public call crosses into native code that owns the handle lifetime |
| native wakeup thread -> Dart isolate | `NativeCallable.listener` invokes `_onWakeup` after the handle may be under teardown |
| user hook / listener -> teardown path | Application code runs synchronously inside `Player.dispose()` and event dispatch |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | `Mpv.dispose` / wakeup callback | high | mitigate | Null the wakeup callback while the handle is alive, shut down stream bridges, destroy the handle, then close the `NativeCallable`; `_onWakeup` exits on `_disposed`. |
| T-01-02 | Tampering | `Player.dispose` / `Mpv.dispose` | high | mitigate | Idempotent `_disposed` early return in both; hook list snapshotted and cleared; second-dispose regression test. |
| T-01-03 | Denial of Service | `Player` state streams | high | mitigate | Register `position`/`decodeWarning` in `_states`; close every controller unconditionally after teardown; 1000-cycle closure test lands in plan 03. |
| T-01-04 | Tampering | `Player.dispose` hook loop | high | mitigate | Per-stage `on Object catch`, collect errors, complete all teardown, then rethrow; the native core is never skipped. |
| T-01-SC | Tampering | Package installs | high | mitigate | No npm/pip/cargo/pub install task in this plan; `package:meta` is already a direct dependency, so the package-legitimacy gate is not triggered. |
