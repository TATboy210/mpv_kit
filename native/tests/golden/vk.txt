# Vulkan-path golden traces of the shared video renderer
# (video_renderer_golden_vk.cc, harness in renderer_harness.h).
#
# One [scenario] per section, one expected line per line; lines starting
# with '#' are comments. Only ever read by the test: an expectation changes
# only by editing this file in a reviewed commit.
#
# Serials number the images FakeVulkanInterop created in this scenario, in
# CreateImage order from 1. `<device>` stands for the runner's Vulkan device
# name. `acquire index=-1 ... serial=none` is an AcquireFront with no front
# frame; index=-2 is the previous generation's retired front frame.

# A frame becomes the front only once its timeline value was signalled:
# while frame 1's GPU work is outstanding AcquireFront has nothing to show,
# after the signal it returns frame 1. Then three frames that complete at
# once rotate through the ring (latency 2, ring 5), and every image is
# destroyed exactly once at teardown.
